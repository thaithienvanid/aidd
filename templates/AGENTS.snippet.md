## Change control

This repository uses aidd. Before you plan, implement, or ship any change, load the skill at `.agents/skills/aidd/SKILL.md` and follow `.agents/skills/aidd/references/loop.md`. The `aidd/gate` status decides whether a change may merge. Agents never approve, merge, or edit the tests after the Spec is approved. Mark every commit you author with `Assisted-by: <harness>/<model>`.
