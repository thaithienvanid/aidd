# Feedback log: {{title}}

Started {{today}}. A living log (`aidd new feedback <topic>`, in `docs/feedback/`). It holds one row per piece of
post-launch feedback, added as it arrives. Feedback comes from support, sales, interviews, reviews, surveys, or
analytics. `aidd digest` counts the themes and severities in its window, and the NPS when rows carry a score; the
product manager reads it at Learn. The product manager is the only agent that writes it. An agent drafts an entry with
its source, and a person confirms each one before it counts.

<!-- One log per product or launch, not per Spec. A row is what one customer said or did, never a summary of many.
     Write the prose at the `ste-80` level (the `aidd-team:plain-language` skill). The columns:
     - Date: when it was said (YYYY-MM-DD); rows without a date are not counted.

     - Score: the 0-10 answer to "How likely are you to recommend us?", when asked; blank otherwise.
     - Linked Spec or hypothesis: the Spec that shipped the feature, or the hypothesis it tests (`SPEC-12` or `SPEC-12
       hypothesis`). Leave it blank when none does yet: that row is a candidate for the backlog. -->
