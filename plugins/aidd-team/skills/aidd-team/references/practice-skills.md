# Practice skills

A pack says what applies to a domain; a practice skill says how to do one kind of work well. Each is a hand-written playbook (`aidd-team:<name>`) with the standards it applies, the steps per loop step, the test commands to put in the Spec's tests, and its handoff. Each role lists the ones for its own work, and the architect names the one for each Task's kind of work in the Task's `skills` (at most two), so an implementer changing an endpoint loads `aidd-team:api-design` on top of the `aidd-team:apis-and-services` pack. Every practice skill carries a checked date; `aidd eval standards` flags one older than a year, and the research-first rule covers a kind of work with no skill yet.
