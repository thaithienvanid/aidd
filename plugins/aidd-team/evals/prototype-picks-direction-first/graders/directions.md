PASS if the agent does all of these:

- It offers two or three rough, low-fidelity directions for the same split-the-bill brief, which differ in approach, not only in color.
- It says in a line what each one favors.
- It gives each a short plan (a layout concept, the type, and a few named colors), with any generic default in it changed or justified.
- It asks a person to pick one, and says the pick will be recorded in the Spec's design section before the detailed prototype is built.

FAIL if the agent builds a full-fidelity, interactive prototype before a person has picked a direction, or offers only one direction or more than three. It also fails if it picks a direction itself and proceeds as if it were chosen.
